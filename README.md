# bibliotecas-frontend

Interfaz web (React + TypeScript + Vite) para registrar bibliotecas y consultar sus libros.

## Requisitos
- Node.js 18+
- El backend `bibliotecas-backend` ejecutándose en http://localhost:8081

## Ejecución

```
npm install
npm run dev
```

Disponible en http://localhost:5173
"# bibliotecas-frontend"
